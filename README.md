# Orçamentos — Atualizações

Canal oficial de distribuição das versões do aplicativo **Orçamentos** para Windows.

Os instaladores ficam na seção **Releases**. Este repositório não contém o código-fonte, o emissor de licenças nem chaves privadas.

## Instalação

1. Abra a versão mais recente em **Releases**.
2. Baixe o arquivo `Orcamentos-Setup-<versão>.exe`.
3. Feche o aplicativo antes de executar a atualização.
4. Conclua o assistente de instalação.

O próprio aplicativo consulta este repositório para avisar quando houver uma versão mais recente.

## Histórico de versões

As notas completas das versões estão reunidas em [NOTAS-DE-ATUALIZACAO.md](NOTAS-DE-ATUALIZACAO.md). Os instaladores correspondentes ficam em **Releases**.

- 6.6.0 — versão mais recente recomendada, com garantias, funil comercial e licença cifrada.
- 6.4.3 — ordenação por atualização e refinamento visual do valor.
- 6.4.2 — refinamento intermediário do quadro “Valor a receber”, incorporado à 6.4.3.
- 6.4.1 — pagamento confirmado automaticamente ao finalizar.
- 6.4.0 — indicadores reconciliados, novo seletor de status e PDF alinhado.
- 6.3.1 — atualização automática do painel técnico na rede local.
- 6.3.0 — painel técnico local, restauração de backup e revisão dos prazos.
- 6.2.0 — painel comercial, peças e melhorias operacionais.
- 6.1.0 — melhorias operacionais, histórico, peças, licença e PDFs.
- 6.0.2 — correções visuais e validação dos campos obrigatórios.
- 6.0.1 — versão intermediária de manutenção, substituída pela 6.0.2.
- 6.0.0 — identidade multiempresa, segurança e personalização.
- 5.0.0 — clientes, aparelhos, backup, permissões e logs.
- 4.0.0 — início da linha neutra e reutilizável do aplicativo.

## Segurança

O instalador 6.6.0 possui assinatura de código autoassinada. Ela identifica o responsável pelo arquivo, mas o Windows SmartScreen ainda pode exibir aviso enquanto o certificado não estiver instalado como confiável no computador.
