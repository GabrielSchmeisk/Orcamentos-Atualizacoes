# Orçamentos — Atualizações

Canal oficial de distribuição das versões do aplicativo **Orçamentos** para Windows.

Os instaladores ficam na seção **Releases**. Este repositório não contém o código-fonte, o emissor de licenças nem chaves privadas.

## Instalação

1. Abra a versão mais recente em **Releases**.
2. Baixe o arquivo `Orcamentos-Setup-<versão>.exe`.
3. Feche o aplicativo antes de executar a atualização.
4. Conclua o assistente de instalação.

O próprio aplicativo consulta este repositório para avisar quando houver uma versão mais recente.

## Histórico de versões

As notas completas das versões 4.0.0 a 6.2.0 estão reunidas em [NOTAS-DE-ATUALIZACAO.md](NOTAS-DE-ATUALIZACAO.md). Os instaladores correspondentes ficam em **Releases**.

- 6.2.0 — versão mais recente recomendada.
- 6.1.0 — melhorias operacionais, histórico, peças, licença e PDFs.
- 6.0.2 — correções visuais e validação dos campos obrigatórios.
- 6.0.1 — versão intermediária de manutenção, substituída pela 6.0.2.
- 6.0.0 — identidade multiempresa, segurança e personalização.
- 5.0.0 — clientes, aparelhos, backup, permissões e logs.
- 4.0.0 — início da linha neutra e reutilizável do aplicativo.

## Segurança

Os instaladores atuais ainda não possuem assinatura digital de código. Por isso, o Windows SmartScreen pode exibir um aviso mesmo quando o arquivo foi baixado deste repositório oficial.
